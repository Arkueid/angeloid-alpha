# Joint限制参数说明

※变更Joint时建议初始化参数/限制值

## 通用

限制 : A - B | 范围(移动:空间距离/旋转:轴旋转度数)

 A < B | 按范围限制
 A = B | 按指定值锁定(由于与刚体的距离偏差等原因,无法完全锁定)
 A > B | 无限制(自由)

## 弹簧6DOF

弹簧 : 使用弹簧计算的系数值

## ConeTwist

限制/参数
dp_x : damping(0) - fixThresh(1) | 0-0时物理计算可能损坏
dp_z : (固定)电机有效(0:OFF/1:ON) - 电机脉冲值

旋转 : X/Y/Z轴周围的旋转范围(正负共用) | x:60 -> -60~+60

※正确地说,对于轴向方向(以初始姿态的X轴为基准):
 X : 扭转方向
 Y : 旋转范围的扩展-横向(纵向)
 Z : 旋转范围的扩展-纵向(横向)
基准轴向可从[轴向]设置固定方向(+-XYZ)

参数/电机角
fc : softness, biasFactor, relaxationFactor | Joint参数(标准:1/0.3/1)
MtA : 电机有效时的固定?角度(X/Y/Z)

※(固定)电机的行为(问题点)
・旋转范围的Z需要60(度)以上(没有的话旋转范围会损坏)
・会按指定角度固定(规格?)

连续旋转推荐使用下面的 Hinge 电机

## Slider

移动/旋转轴以"X轴"方向为基准(轴方向通过Joint方向改变应对)
※[轴向]可设置固定方向(+-XYZ)

电机
移动/旋转(共用) : 电机有效(0:OFF/1:ON), 电机速度, 电机最大力

※Slider的旋转控制在某些范围内可能无法正确动作

## Hinge

旋转轴以"Z轴"方向为基准(轴方向通过Joint方向改变应对)
※[轴向]可设置固定方向(+-XYZ)

参数/电机
fc : softness, biasFactor, relaxationFactor | Joint参数(标准:0.9/0.3/1)
旋转 : 旋转电机有效(0:OFF/1:ON), 电机速度, 电机最大力

※将旋转限制设为自由(-180~+180/1~0等)并使用电机可实现连续旋转
